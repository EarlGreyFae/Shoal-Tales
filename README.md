# Shoreline Dredge

Single-file browser prototype of the design in the "Dredging Game Ideas" doc. Open `index.html` — no build, saves to localStorage.

**Implemented:** dredge timer, sorting into 6 bins with streak multiplier, curio cleaning + rarity, Collector's Log, magic curios (permanent buffs, full-set bonus), crates, bottles (lore letters, community letters with voting, empty bottles), animals to dismiss, stations (cutting board, oven, crucible, carpentry, recycler), storage/selling, work-table upgrades, map depths, prestige with titles, letter-writing warning + rules, max 3 pending letters.

**Not implemented (needs a backend):** guilds, parties, guild chat/quests, real shared letters and moderation queue (currently a local seed pool + local queue). Lore letters are placeholders — replace `LETTERS` in `index.html`.
